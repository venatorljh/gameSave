# 大世界地图美术素材

这套素材用于大世界地图界面：地形底图承载整体地理环境，地区图标代表可进入的小地图。地图底图、地区图标和道路分别组织，方便后续实现每局随机的网状连接。

## 来源与风格

- 本次素材使用内置 `image_gen` 原创生成；没有下载新的网上素材。
- 项目现有瓦片与地图预览仅作为配色、材质和视角参考，没有直接裁取现有瓦片拼成本套图像。参考内容和生成提示保存在 `generation_prompts.json`，组合预览提示词另存于 `preview_generation_prompt.txt`。
- 风格采用低饱和的中世纪俯视 RPG 像素：灰绿植被、黄褐土路、灰紫石材、米灰墙面、深褐木梁和暗红屋顶。
- 本次仅提供美术素材，尚未接入游戏的场景、交互或地图生成逻辑。

## 目录

| 目录 / 文件 | 用途 |
|---|---|
| `backgrounds/` | 大世界地形底图；当前底图为 `world_terrain_v1.png` |
| `atlases/` | 地区图标整张图集，便于查看整体风格与来源排列 |
| `icons/` | 24 个独立透明 PNG，统一为 128×128，建议优先使用 |
| `icons_64/` | 同一套图标的 64×64 版本，适合更紧凑的像素地图界面 |
| `icons_source/` | 按透明间隙裁出的原尺寸独立图标，保留生成细节 |
| `previews/` | 图标总览 PNG 与地图组合浏览预览，供挑选和查看搭配 |
| `generation_prompts.json` | 生成方式、参考图像、提示词及地区名称顺序 |
| `manifest.json` | 最终文件清单、尺寸与图集切分信息；实际尺寸以此文件为准 |

底图原尺寸为 1536×1024，另有最近邻缩小的 768×512 和 384×256 版本。图集原尺寸为 1536×1024，排列为 6 列、4 行；生成图各行间距略有偏差，因此已经按透明间隙切好，使用独立图标即可。独立图标保留原 PNG 的透明度，不带预览格子的深灰背景。

`previews/region_icons_contact_sheet.png` 是带中文名称的图标总览。它的背景、边框和文字仅用于浏览，不属于图标本体。

`previews/world_map_layout_preview.html` 可用浏览器打开，使用本套底图和独立图标显示一份网状布局示例，可切换为纯地形查看。该预览采用已有 PNG 图层组合，包含出发点、8 个普通地区、Boss 与示例连线；位置和道路不代表最终生成规则。组合预览未在浏览器中完成视觉核看，因为当前工具不允许打开本地 HTML。

## Godot 中的使用建议

1. 地形底图作为地图界面的背景单独显示，地区节点使用 `icons/` 内的独立透明 PNG。文件及实际尺寸以 `manifest.json` 为准。
2. 像素纹理使用 **Nearest（最近邻）** 过滤，避免缩放时模糊。尽量采用整数倍缩放，同一地图统一使用 128 或 64 这一尺寸版本；图标不必与小地图中实际建筑采用相同世界尺寸。
3. 道路与连线由地图系统根据本局网络单独绘制，不烘焙到地形底图或图标。这样可以变化地区位置、连接、环路和替代路线。
4. 将节点交互范围、选中状态、当前位置、已探索标记和迷雾作为独立 UI 或图形叠层。原始图标负责地区外观，不承担这些状态逻辑。
5. 预览图片用于看整体效果；后续实际节点应引用独立图标与地形底图，避免把预览组合图当作固定路线地图。
