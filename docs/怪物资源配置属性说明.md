# 怪物资源配置属性说明

怪物使用同一个场景 `godot-game/scenes/monsters/monster.tscn`。在地图中选中怪物实例，修改其 **Monster Config** 属性，即可指定一份 `MonsterConfig`（`.tres`）资源。资源决定怪物的参数和图片；血量、当前目标、攻击冷却等运行状态保存在各个怪物实例中，不会写回资源。

本说明对应 `godot-game/scripts/monsters/monster_config.gd`。表中的“骷髅 / 眼球”是当前 `skeleton.tres` 和 `eyeball.tres` 的值；未在 `.tres` 文件中显式写出的值会沿用脚本默认值。距离和尺寸单位都是 Godot 世界中的**像素**，速度单位是**像素/秒**，时间单位是**秒**。`Vector2(x, y)` 中正 X 向右、正 Y 向下。

## 基础

| 属性 | 含义 | 骷髅 / 眼球 |
| --- | --- | --- |
| `monster_id` | 怪物的内部标识。当前脚本仅保存它，暂不参与战斗逻辑；以后可用于掉落表、存档或图鉴。建议每种怪物使用唯一值。 | `skeleton` / `eyeball` |
| `display_name` | 给人看的名称。当前怪物脚本尚未把它显示在游戏 UI 中。 | 骷髅怪 / 眼球怪 |
| `max_health` | 出生时的最大生命值。受到攻击时扣血，降到 0 后播放死亡动画并移除。 | 42 / 22 |
| `contact_damage` | **一次攻击命中**玩家时造成的伤害，不是站在怪物身边持续扣血。一次攻击对同一目标最多命中一次。 | 8 / 10 |

## 巡逻与锁敌

| 属性 | 含义 | 骷髅 / 眼球 |
| --- | --- | --- |
| `patrol_radius` | 以怪物出生位置为中心的巡逻半径。每次随机选择约半径 30%～100% 处的一个目的地；设为 0 时会留在出生点附近。 | 42 / 34 px |
| `patrol_speed` | 巡逻时的移动速度。 | 27 / 33 px/s |
| `chase_speed` | 追赶玩家时的移动速度。冲撞攻击期间另用 `charge_speed`。 | 68 / 82 px/s |
| `detection_radius` | `DetectionArea` 的圆形感知半径。玩家进入后成为目标并触发追赶，离开后返回巡逻。圆心会受到 `body_offset` 影响。 | 96 / 110 px |
| `max_chase_distance` | 怪物离**自己出生位置**的最大追赶距离。超过后放弃当前目标并返回巡逻，用于避免无限追逐。它不是怪物与玩家之间的最大距离。 | 190 / 220 px |
| `patrol_pause_seconds` | 到达巡逻点或巡逻时撞墙后，停顿多久再选新目的地。 | 0.7 / 0.5 s |

目前的追赶是直接朝玩家移动，没有绕障碍寻路。复杂地形中怪物可能卡在障碍旁。

## 攻击

| 属性 | 含义 | 骷髅 / 眼球 |
| --- | --- | --- |
| `attack_kind` | 攻击行为。`ARM_SWING`：停下并用身体前方的命中区域挥臂攻击；`CHARGE`：锁定前摇时玩家所在方向，随后沿直线冲撞，撞上障碍会结束冲撞。 | `ARM_SWING` / `CHARGE` |
| `attack_range` | 追赶时，怪物与玩家的**场景节点位置**相距不超过此值，就可以在冷却结束后发起攻击。它是起手距离，并非实际命中范围。 | 29 / 52 px |
| `attack_cooldown` | 从进入攻击前摇开始计算的冷却时间。冷却结束后，还需完成当前攻击及恢复动作，才能再次起手。 | 1.1 / 1.35 s |
| `attack_windup` | 攻击前摇时间。此时怪物停止移动、开始播放攻击动画，并锁定攻击方向；尚不会造成伤害。 | 0.20 / 0.22 s |
| `attack_active_seconds` | 攻击的有效时间。挥臂期间命中区域生效；冲撞期间按 `charge_speed` 移动并尝试命中。 | 0.16 / 0.28 s |
| `attack_recovery` | 有效时间结束后的收招时间；结束后再追赶或巡逻。 | 0.28 / 0.28 s |
| `hitbox_radius` | `AttackArea` 圆形命中区域的半径。挥臂使用前方圆形判定，并不是严格的半圆形判定；冲撞时圆心回到身体处。 | 12 / 10 px |
| `hitbox_forward_offset` | 挥臂攻击时，命中区域沿锁定的攻击方向从身体中心向前移动的距离。冲撞时该值不参与命中位置计算。 | 17 / 0 px |
| `charge_speed` | `CHARGE` 冲撞阶段的直线移动速度；`ARM_SWING` 不使用。无障碍时，理论冲撞距离约为 `charge_speed × attack_active_seconds`。 | 200（未使用）/ 230 px/s |

`AttackArea` 只侦测玩家。攻击动画从**前摇开始**播放，`attack_windup`、`attack_active_seconds`、`attack_recovery` 与 `attack_fps` 可以一起调整，让画面与命中时机更一致。

## 碰撞与外观

| 属性 | 含义 | 骷髅 / 眼球 |
| --- | --- | --- |
| `body_radius` | 怪物本体胶囊形碰撞箱的半径，也决定宽度（宽为半径的 2 倍）。 | 6 / 7 px |
| `body_height` | 本体胶囊形碰撞箱的总高度。脚本会确保它不小于 `body_radius × 2`。 | 22 / 14 px |
| `body_offset` | 本体碰撞箱相对怪物节点的位置。感知区和攻击区的基础位置也使用此偏移；负 Y 表示向上。 | `(0, -11)` / `(0, -10)` px |
| `sprite_offset` | 动画图片相对怪物节点的位置。用于让画出的脚和碰撞箱落在合适的位置，不改变物理判定。 | `(0, -16)` / `(0, -12)` px |
| `sprite_scale` | 巡逻、追赶和攻击动画的显示倍率，分别用 X/Y 控制宽高。例如 `(1.4, 1.4)` 表示放大到 1.4 倍。 | `(1.45, 1.45)` / `(1.4, 1.4)` |
| `death_sprite_scale` | 死亡动画单独使用的显示倍率。眼球炸裂图的原始单格比主图大得多，因此设为 `(0.06, 0.06)`。 | `(1.45, 1.45)` / `(0.06, 0.06)` |
| `art_faces_right` | 原图默认是否面朝右。脚本根据目标在左还是在右水平翻转图片；目前没有四方向专用怪物图。 | `true` / `false` |

## 逐帧图

主图按规则网格切割：每格大小由 `frame_size` 指定，每排读取从左到右的 `frames_per_row` 帧；行号从 **0** 开始。`patrol_rows`、`chase_rows` 和 `attack_rows` 指定各动作使用哪些行。多个行号会按顺序接成一段动画。

| 属性 | 含义 | 骷髅 / 眼球 |
| --- | --- | --- |
| `sprite_sheet` | 巡逻、追赶、攻击使用的主精灵图。 | `skeleton_spritesheet_calciumtrice.png` / `eyeball_spritesheet.png` |
| `frame_size` | 主图**单帧**的宽、高，不是整张图片尺寸。 | `(32, 32)` / `(32, 32)` px |
| `frames_per_row` | 每个动作行读取的帧数；目前会读取所选行的前 N 格，不能单独跳过某一格。 | 10 / 8 |
| `patrol_rows` | 巡逻动画所用的行号列表。巡逻动画循环播放。 | `[0, 1]`（第 1、2 排）/ `[0]`（第 1 排） |
| `chase_rows` | 追赶动画所用的行号列表。追赶动画循环播放。 | `[2]`（第 3 排）/ `[1]`（第 2 排） |
| `attack_rows` | 攻击动画所用的行号列表。攻击动画播放一次，不循环。 | `[3]`（第 4 排）/ `[2]`（第 3 排） |
| `patrol_fps` | 巡逻动画每秒播放的帧数，只改变画面速度，不改变移动速度。 | 10 / 8 帧/秒 |
| `chase_fps` | 追赶动画每秒播放的帧数。 | 12 / 12 帧/秒 |
| `attack_fps` | 攻击动画每秒播放的帧数。 | 16 / 11 帧/秒 |

例如骷髅图是 10 列、5 排，每格 `32×32`：巡逻使用第 1、2 排共 20 帧，追赶用第 3 排，挥臂用第 4 排；死亡动画用第 5 排。眼球主图是 8 列、3 排，每格 `32×32`。

## 死亡逐帧图

死亡动画只播放一次；播放完成后怪物节点会被移除。死亡时身体碰撞和侦测也会关闭。

| 属性 | 含义 | 骷髅 / 眼球 |
| --- | --- | --- |
| `death_sheet` | 可选的独立死亡精灵图。留空就从 `sprite_sheet` 中切死亡帧。 | 留空，沿用主图 / `eyeball_death_spritesheet.png` |
| `death_frame_size` | 死亡图单帧的宽、高。使用独立图片时，按该图片的实际格子尺寸填写。 | `(32, 32)` / `(543, 724)` px |
| `death_frames_per_row` | 死亡图每排读取的帧数。 | 10 / 4 |
| `death_rows` | 死亡动画所用的行号列表，仍从 0 开始。 | `[4]`（主图第 5 排）/ `[0]`（独立图第 1 排） |
| `death_fps` | 死亡动画每秒播放的帧数。 | 12 / 10 帧/秒 |

## 调参时先看这里

- 想让怪物更早发现玩家：增大 `detection_radius`。想让它追得更远：增大 `max_chase_distance`。
- 想让攻击更容易命中：调整 `attack_range`（何时起手）、`hitbox_radius`（实际命中圈）和挥臂用的 `hitbox_forward_offset`；三者职责不同。
- 想让眼球冲得更远：调整 `charge_speed` 或 `attack_active_seconds`。增大后也应检查命中和撞墙时的表现。
- 图片错位时先调 `sprite_offset`，不要直接改变 `body_offset`；后者也会移动碰撞、感知和命中区域。
- 换新图片时核对单格尺寸、列数和从 0 开始的行号。如果填入的行或列超出图片边界，对应帧会被跳过。
