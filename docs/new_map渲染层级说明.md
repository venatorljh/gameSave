# new_map 渲染层级说明

`new_map` 采用按落地点排序的方式处理人物与房屋、树木、围栏之间的前后遮挡。人物走到物件前方时会挡住接近地面的部分；走到物件后方时会被物件遮挡。原有瓦片的 `tile_map_data`、TileSet、贴图和绘制位置保持不变，排序规则单独配置。

## 场景中的层级

地图根节点开启 `Y Sort Enabled`。`Floors`、`WallsAndBuildings`、`house`、`Props`、`Overhead` 都设为 `Z Index = 0` 并开启 Y 排序，这样它们才能与人物比较前后位置。

`Ground`、`Water`、`TerrainDetails`、`GeneratedGrasslandDraft` 保持原来的负 Z，作为地面和水面绘制在人物下方。`Floors` 中未匹配规则的格子按地面处理，绘制 Z 为 `-10`；其他参与排序的层中，透明或地面用途的 source 0、source 3 格子使用 `-5`。

一幢房屋即使由多个层组成，也共用一个落地点 Y。例如墙体在 `WallsAndBuildings`、屋顶在 `Props`，它们仍会作为完整房屋与人物比较，不会出现人物穿插在房屋不同排瓦片之间的情况。

圆塔平顶、石墙顶部和南门拱梁使用固定上层 `draw_z = 2`，遮挡与这些部分重叠的人物。塔身、墙脚仍按落地点排序；门洞内的透明区域仍然保持透明。

### 固定遮挡的顶部

- 东南圆塔：`Floors` 的格子 `(41..44, 6..8)` 是平顶；`WallsAndBuildings` 的第 8 行接边也一起置于上层。塔顶原有的骑士装饰共用同一层级，保留其外观。
- 北圆塔：`Floors` 的格子 `(29..33, -8..-7)` 是平顶，顶部接边和火炬一起置于上层。
- 北侧石墙：顶部平台和边沿单独遮挡人物。
- 南城墙：`Floors` 第 22～24 行的顶部平台，以及城墙上沿、柱体上段和三个圆柱顶盖置于上层。

这些顶部规则排在原来的整幢建筑规则之前。顶部不再按地面处理，人物经过其投影范围时会被遮挡；瓦片的位置和图像保持原样。

## 排序配置在哪里

配置资源：`res://resources/maps/new_map_depth_layout.tres`。

在 Godot 的文件系统中选中此资源，可以修改其排序区域列表。每一项是一个 `MapDepthRegion`，属性含义如下：

| 属性 | 含义与填写方式 |
| --- | --- |
| `display_name` | 区域名称或说明，方便识别，例如“西北房屋”“南门拱梁”。 |
| `cell_rect` | 地图格子范围，类型为 `Rect2i`。位置表示左上角格子坐标，尺寸表示格子数量；地图一格为 16 像素。它不是像素矩形。 |
| `layer_names` | 此规则适用的 TileMapLayer 节点名列表，例如 `WallsAndBuildings`、`Props`。空列表表示适用于全部参与排序的层。 |
| `source_id` | 仅匹配某个 TileSet 图集来源；`-1` 表示匹配全部来源。可在 TileSet 编辑器查看来源 ID。 |
| `atlas_rect` | 仅匹配图集中的某个瓦片坐标范围，使用图集格子坐标。尺寸为 0 时不限制图集坐标。 |
| `sort_y` | 该物件落地点在地图本地坐标中的 Y 值，单位为像素。通常填写房屋墙脚、树根或围栏底部的位置；Y 越大，越靠画面下方。 |
| `draw_z` | 此区域的绘制 Z。普通立体物件使用 `0`，参与人物前后排序；固定遮挡的塔顶、墙顶、门洞拱梁使用 `2`，绘制在人物上方。 |

区域条件需要同时满足才会匹配。规则从列表上到下检查，**第一个匹配的规则生效**，因此门洞拱梁、单棵树等更具体的规则应放在大范围房屋或城墙规则之前。

例如，一幢房屋的底边在地图本地 `Y = 256`，可以将房屋相关格子的 `sort_y` 都设为 `256`。这并不会移动瓦片，只会改变用于比较前后关系的落地点。

## 人物的排序点

人物根节点开启 Y 排序。其下的 `VisualSortOrigin` 节点位于 `(11, -14)`，代表人物脚底的位置。

`AnimatedSprite2D` 是 `VisualSortOrigin` 的子节点，局部位置为 `(0, -3)`，Z 为 `0`。两者位置相加仍为原来的 `(11, -17)`，因此人物图片的显示位置保持不变，只是使用脚点参与地图排序。

## 后续绘制和调整

### 技能的遮挡

魔法子弹和斩击的图像都在各自的 `VisualSortOrigin` 下，使用 `Z = 0`，与人物一起参与地图 Y 排序。共享脚本为 `res://scripts/projectiles/attack_visual_sort_origin.gd`。

- 斩击使用施法人物的脚点作为排序位置。调整排序点时会补偿图片局部坐标，保留原攻击位置、方向、碰撞范围和动作。
- 魔法子弹发射时记录人物脚点与发射点之间的偏移，此后排序点随子弹飞行移动。
- 魔法尾迹与子弹图像处于同一个排序组。历史点保存在世界坐标中，保持原来的轨迹；消失时保留最后的排序点再淡出。

因此，固定上层的塔顶、墙顶和拱梁会遮挡技能；普通建筑仍按落地点决定技能在前还是在后。

### 地图绘制

1. 添加房屋、树木或围栏后，在排序资源中新增区域规则，填写覆盖它们的 `cell_rect`。
2. 以墙脚或树根确定 `sort_y`。同一物件跨越多个层时，确保这些层都匹配到相同的 `sort_y`。
3. 若某一小块需要特殊遮挡，先添加更具体的规则，并放在大区域规则前面。
4. 地面贴花、道路和水面继续放在地面层；不要为了让屋顶遮挡人物而重新把整个 `Props` 设为 10、`Overhead` 设为 20，这会使该层所有格子始终遮挡人物。

首次调整核对了九个瓦片层的原始数据，并做了静态贴图合成对照，地图外观一致。本次追加顶部遮挡只修改排序资源，未修改地图场景的瓦片数据或 TileSet；尚未启动 Godot 运行游戏验证。
