# 人物体力与翻滚配置说明

## 在哪里调整

打开人物场景 `res://scenes/characters/goofy_veil_girl.tscn`，选中根节点 **GoofyVeilGirl**，在检查器中展开 **体力**、**翻滚**、**人物图像** 分组。下表中的英文名是 Godot 检查器显示的属性名，括号中是脚本变量名。

右上角的绿色 **SP** 条表示体力，红色 **HP** 条表示生命，蓝色 **MP** 条表示魔力。体力从上限值开始，最低为 0。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD | 移动；同时按两个方向键可斜向移动。普通行走不消耗体力，也允许恢复体力。 |
| Shift + WASD | 加速跑，持续消耗体力。 |
| 空格 | 翻滚，一次扣除翻滚消耗的体力。 |
| J | 魔法攻击，同时消耗体力和魔力。 |
| K | 斩击，消耗体力。 |

体力不足以支付攻击或翻滚消耗时，该动作不会发动。魔法攻击失败时，也不会扣魔力或启动攻击冷却。跑步耗尽体力后会自动改为普通行走。

## 体力分组

| 检查器属性（变量名） | 默认值 | 含义 |
| --- | --- | --- |
| Max Stamina（`max_stamina`） | 100 | 体力上限，开始游戏时体力为这个值。 |
| Stamina Regeneration Per Second（`stamina_regeneration_per_second`） | 20 点/秒 | 满足恢复条件时每秒恢复的体力。设为 0 会关闭自动恢复。 |
| Stamina Regeneration Delay（`stamina_regeneration_delay`） | 0.8 秒 | 每次消耗体力后，至少等待这么久才允许恢复；再次消耗会重新计时。 |
| Sprint Stamina Per Second（`sprint_stamina_per_second`） | 18 点/秒 | 实际加速跑动时的持续消耗。仅按住 Shift、不移动不会消耗。 |
| Magic Stamina Cost（`magic_stamina_cost`） | 12 点 | 每次成功释放魔法的体力消耗。 |
| Slash Stamina Cost（`slash_stamina_cost`） | 18 点 | 每次成功斩击的体力消耗。 |
| Roll Stamina Cost（`roll_stamina_cost`） | 16 点 | 开始一次翻滚时扣除的体力，不随翻滚距离分次扣除。 |

**恢复条件：**人物静止或普通行走、没有正在翻滚、没有处于翻滚后的恢复时间，并且消耗后的恢复延迟已经结束。加速跑时不能恢复体力；连续攻击会不断推迟恢复。人物生命归零后停止恢复。

魔法另外受 **Magic Mana Cost（`magic_mana_cost`）** 控制，默认每次消耗 **12 点魔力**。体力和魔力必须同时足够才会释放魔法。

## 翻滚分组

| 检查器属性（变量名） | 默认值 | 含义 |
| --- | --- | --- |
| Roll Distance（`roll_distance`） | 64 世界像素 | 无障碍时一次翻滚的移动距离。当前地图每格 16 像素，约等于 4 格瓦片。它不受窗口缩放影响。 |
| Roll Duration（`roll_duration`） | 0.6 秒 | 翻滚动作和位移的总时长。动画会随此值调整播放速度；距离不变时，时间越短，翻滚越快。 |
| Roll Invulnerability Start（`roll_invulnerability_start`） | 0 秒 | 从翻滚开始多久后进入无敌窗口。设为 0 表示发动后立即进入。 |
| Roll Invulnerability Duration（`roll_invulnerability_duration`） | 0.43 秒 | 无敌窗口的持续时间。在这个窗口内不接受攻击伤害；窗口最晚在翻滚结束时终止。 |
| Roll Recovery Time（`roll_recovery_time`） | 0.1 秒 | 翻滚动作结束后，再次攻击或翻滚的等待时间；这段时间也不能恢复体力，但可以行走或加速跑。 |

开始翻滚时优先采用当前 WASD 方向；没有按方向键时，沿人物面朝方向翻滚。方向在开始后锁定，途中松开或改按方向键不会改变这一滚的方向。位移支持斜向，动画使用上、下、左、右四个对应视图。

翻滚保留人物与墙、建筑等障碍物的实体碰撞。撞墙时实际移动距离可能小于设置值，不能靠翻滚穿墙。位移前段较快、落地前逐渐减速。翻滚中不能攻击或再次翻滚。

**默认时间关系：**开始后的 `0～0.43 秒` 为无敌窗口，`0.43～0.6 秒` 的动作尾段和随后 `0.1 秒` 的恢复时间都可以受到伤害。无敌时间与整个动画时长是两个独立参数。

## 人物图像分组与翻滚素材

| 检查器属性（变量名） | 当前场景值 | 含义 |
| --- | --- | --- |
| Image Scale（`image_scale`） | 0.045 | 普通人物图像的缩放比例，也作为翻滚图像缩放的基础。修改它不会同步改变碰撞箱。 |
| Roll Image Scale Multiplier（`roll_image_scale_multiplier`） | 1.35 | 翻滚图像相对于普通图像的额外缩放。最终比例为 `Image Scale × 此值`，可用它匹配两套素材中的人物大小。 |
| Roll Image Offset（`roll_image_offset`） | `(0, -185)` | 翻滚图片在精灵内的偏移，单位为缩放前的图片像素。X 控制左右，Y 控制上下，负 Y 向上；用于对齐翻滚人物与原人物的落地点。 |

普通动作由 `VisualSortOrigin/AnimatedSprite2D` 显示，翻滚动作由 **`VisualSortOrigin/RollSprite2D`** 显示。两者共享原人物的遮挡排序位置，翻滚时切换显示对应精灵。

翻滚动画资源为 `res://assets/art/characters/npc/roll/goofy_veil_girl_roll_frames.tres`。它使用同目录中的四张方向图，每张图按 **3 列 × 2 行** 切成 **6 帧**，每帧 **512 × 512 像素**。播放顺序是第一行从左到右，再播放第二行从左到右；四个动画名分别为 `roll_down`、`roll_left`、`roll_right`、`roll_up`。调整大小和偏移时优先修改根节点的上述属性。

## 《黑暗之魂 3》参考与本游戏取值

社区 Wiki 的 [Stamina 页面](https://darksouls3.wikidot.com/stamina) 记录：原作翻滚消耗为 **16 点体力**，基础恢复速度为 **45 点/秒**。本游戏沿用 16 点翻滚消耗，恢复速度初步采用较慢的 **20 点/秒**，配合当前休闲战斗节奏。

社区 Wiki 的 [Combat Game Mechanics 页面](https://darksouls3.wikidot.com/combat-game-mechanics) 将轻、中负重翻滚的无敌窗口列为 60 FPS 下的 `0～26` 帧；按 `26 ÷ 60` 换算约为 **0.43 秒**，作为当前无敌时间的参考。

**64 像素距离、0.6 秒动作时长、20 点/秒恢复速度以及其他消耗和延迟，是适配本游戏地图尺度的初始参数。**翻滚距离用本项目的世界像素定义；没有把它声称为原作的精确米数。之后可以直接在人物场景中调整这些值来改变手感。
