# 物品栏系统说明

## 操作与生效时机

- **Tab**：打开或关闭物品栏，游戏继续运行。
- **Esc**：有详情卡时先关闭详情卡，再按一次关闭物品栏；主面板关闭按钮直接关闭物品栏。
- **鼠标单击有物品的格子**：在主面板旁边显示一张小详情卡，介绍道具名称、描述和持有数量。未选择物品时不显示详情卡。
- **使用按钮**：使用所选道具，每次消耗一个；无法生效时保留物品并显示原因。
- 宝箱仍使用 **E** 打开，掉出的物品接触人物后进入物品栏。
- 打开物品栏时仍可使用 **WASD、Shift、J、K、空格** 操作人物。人物、怪物和已生效增益的倒计时继续运行。

普通地面道具和宝箱掉落使用同一收纳逻辑，拾取时不再立即触发效果。重复收集的同一种道具合并显示数量，暂不设置容量限制。

满血时也能收集回复药水，受伤后再使用；满血时点击使用不会消耗药水。增益达到叠加上限后仍可收集，但不能继续使用达到上限的本局增益。

限时增益从**使用时**开始计时；重复使用遵循原资源中的叠加上限，并刷新持续时间。打开物品栏不会暂停已生效增益的倒计时。使用道具不额外消耗魔力或体力。

翻滚中也能打开物品栏，但人物翻滚或处于翻滚结束后的等待时间时不能使用道具。详情卡中的使用按钮会随人物状态、生命值和增益叠加情况实时刷新。

其他菜单（例如地图传送确认）已经暂停游戏时，不能同时打开物品栏。如果物品栏打开后其他菜单暂停游戏，物品栏会自动收起。物品栏本身不修改游戏的全局暂停状态。

## 格子布局与外观

- 主面板在同一窗口大小下保持相同尺寸，空包和有物品时不会因内容数量改变大小。
- 标准布局为 **5 列 × 4 行，共 20 个可见格子**，未占用的格子保留显示。物品种类超过一页时通过分页查看；20 个格子是每页显示数量，不是物品栏容量。
- 极小窗口会根据窗口可用空间减少可见列数和行数。面板尺寸与格子布局只跟窗口大小有关，不跟持有物品数量有关。
- 点击物品后才显示独立的小详情卡；详情卡的出现、关闭和内容变化不改变主面板尺寸。
- 面板和格子使用与血条、蓝条相近的木质底色和紫灰边框，并采用半透明背景。没有全屏变暗遮罩，可以继续观察地图。

## 资源配置继续复用

效果和图片继续来自 `ItemConfig` 资源。目前资源位于 `res://resources/items/`，图片位于 `res://items/`。

| 属性 | 与物品栏的关系 |
| --- | --- |
| `item_id` | 同种道具的识别键；同一个 ID 的道具合并数量。不同道具必须使用不同 ID。 |
| `display_name` | 物品栏中的道具名称。 |
| `description` | 选中道具后显示的描述。 |
| `icon_texture` | 格子显示的道具图标。 |
| `drop_weight` | 宝箱随机抽取的权重，沿用已有宝箱逻辑。 |
| `effect_type`、`strength` | 点击使用时生效的类型和强度。 |
| `duration_mode`、`duration` | 使用后的效果持续方式与时间；存放在包里不会开始计时。 |
| `max_stacks` | **已生效增益**的叠加上限，与物品栏里的数量上限无关。 |

新增同类道具只需配置 `ItemConfig`，再将资源加入宝箱的 `Loot Pool`，或设为 `Fixed Loot`，也可赋给通用 `ItemPickup` 场景的 `Item Config`。物品栏会直接显示和使用该资源，不需要为每个道具创建专属场景。

## 节点与脚本

人物场景：`res://scenes/characters/goofy_veil_girl.tscn`。

| 节点 / 文件 | 职责 |
| --- | --- |
| 人物下的 `Inventory` / `res://scripts/items/item_inventory.gd` | 保存资源和数量，重复收纳合并；只有效果成功应用后才扣除一个。 |
| 人物下的 `PlayerInventoryUI` / `res://scenes/ui/player_inventory_ui.tscn` | 通用物品栏界面，沿用生命、魔力和体力条的配色，固定在屏幕上。 |
| `res://scripts/ui/player_inventory_ui.gd` | Tab 开关、格子分页、独立详情卡、使用按钮和界面刷新；检测其他菜单暂停时自动收起，不设置全局暂停。 |
| `res://scripts/characters/goofy_veil_girl.gd` | 拾取入口与手动使用入口，判断人物状态并发送收纳、使用信号。 |
| 人物下的 `ItemEffects` / `res://scripts/items/item_effect_controller.gd` | 原有增益、治疗、持续时间和效果叠加逻辑。 |
| `res://scripts/items/item_pickup.gd` | 地面接触收纳；防止同一掉落重复进入物品栏。 |

## 数据保留范围

物品栏属于当前人物实例。现有从 `outdoor_map` 到 `new_map` 的传送会移动同一个人物，因此物品和数量会随人物保留。

当前没有新增磁盘存档、跨局继承或死亡结算规则；重新创建人物实例时物品栏从空开始。
